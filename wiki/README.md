## About This Wiki

This wiki is part of the [Cataam open-source initiative](https://github.com/cataam-security/cataam). It is intentionally framework-agnostic and vendor-neutral — the goal is to build the best free GRC reference on the internet.

Contributions are welcome. If a term is missing, wrong, or out of date, open a pull request.
